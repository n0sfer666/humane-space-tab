このAppには作業用のウインドウがありません。メニューバーに常駐し、行うことはすべて、
ショートカットを押している間に起こります。

![リボン](images/ribbon.png)

## 最初の起動

1. インストールします — `brew install --cask n0sfer666/tap/humane-space-tab`、または
   Releases からディスクイメージを開き、**Humane Space Tab.app** を Applications の
   ショートカットにドラッグして、起動します。
2. ダウンロードしたAppは初回は開けません。**システム設定 → プライバシーとセキュリティ**
   を開き、いちばん下までスクロールして **このまま開く** を押し、もう一度起動します。
3. 起動時に **アクセシビリティ** を求められます。**システム設定 → プライバシーと
   セキュリティ → アクセシビリティ** で許可してください。スイッチャーは数秒で働き
   はじめます。再起動は不要です。

メニューバーのアイコンが、Appが動いていることを示す唯一の目印です。働いているときは
`⇄`、働けないときは警告の三角形になります。macOS は許可をコードの署名に結びつけるため、
アップデートのたびに許可し直す必要があります。

## App を切り替える

**⌘** を押したまま **Tab** を叩きます。どうなるかは押している長さで決まります。

- **短く叩く** — 表示までの待ち時間（初期設定は 120 ms）より短い場合 — は、何も表示せずに
  直前のAppへ切り替えます。手が覚えているとおりの動きです。
- **⌘ を押したまま**にすると、**現在の操作スペース**のAppがリボンに並びます。最近使った
  ものが先頭です。さらに **Tab** を叩くたびに選択が1つ進みます。

リボンが開いている間は:

| キー | 働き |
|---|---|
| **Tab** | 1つ進む |
| **⇧Tab** | 1つ戻る |
| **Escape** | 取り消し — 何も切り替わりません |
| **⌘** を離す | 選択中のAppへ切り替える |

選択中のAppは、大きく強く描かれ、下に名前が付いたアイコンです。両隣は薄く抑えられて
います。5つ以上になるとリボンはカルーセルになります。選択は位置を保ち、アイコンが
その下を回るので、1歩の距離は目にとって常に同じで、リストに端はありません。最後のAppの
次は最初のAppです。5つ未満ならアイコンはそれぞれの位置にとどまり、動くのは選択だけです。
リボンは10枠で大きくなるのをやめます。

何も開いていない操作スペースでも、リボンはそこに何もないと伝えます。キー入力をシステムの
スイッチャーに返してしまうことはありません。

## 1つのAppのウインドウを切り替える

**⌘** を押したまま **`**（Tab の上のキー）を叩きます。リボンには最前面のAppのウインドウ
が並びます。現在の操作スペースにあるものだけが、重なり順に、それぞれのタイトルとともに
並びます。操作は同じで、`⇧` は向きを逆にし、Escape は取り消し、**⌘** を離すとその
ウインドウが前に出ます。

システムのショートカットはすべての操作スペースのウインドウをまとめて数えます。別の操作
スペースへ連れて行かれるのはそのためです。こちらはそれができません。ここにないウインドウは
一覧にも載らないので、操作スペースは決して切り替わらず、しまってあるウインドウが戻ることも
ありません。

## マウス

リボンが開いている間、ポインタはリボンの上で働きます。

- アイコンの上で **マウスを動かす** と、そのアイコンが選ばれます。リボンが開いた場所に
  ただ置かれているだけのポインタは、動くまで何も変えません。
- アイコンを **クリック** すると、**⌘** を離すのを待たずにすぐ切り替わります。
- リボンの上で **スクロール** すると、選択が進みます。

## 設定

メニューバーのアイコン → **設定…** から開きます。

![設定](images/settings.png)

| 設定 | 内容 |
|---|---|
| **App** | リボンを開くショートカット。フィールドをクリックして組み合わせを入力するか、**デフォルトに戻す** で `⌘Tab` に戻します。 |
| **最前面のAppのウインドウ** | 2つめのショートカット。初期設定は `` ⌘` `` です。 |
| **リボンを表示する画面** | キーボードフォーカスのある画面か、ポインタのある画面か。 |
| **言語** | インターフェイスの言語。**システム** は macOS に従います。同梱の言語はそれぞれの言語名で並びます。選ぶとウインドウはその場で描き直されます。 |
| **表示までの待ち時間** | リボンが出るまでショートカットを押しておく時間 — 0〜500 ms。`0` なら即座に出ます。 |
| **ログイン時に開く** | Appを macOS にログイン項目として登録します。 |
| **Appではなくウインドウを切り替える** | `⌘Tab` がウインドウを並べるようになります。Windows や Linux と同じ挙動です。初期設定はオフで、オンにすると同じエディタの2つの書類は2つの項目になります。 |
| **操作スペースの非公開レイヤーを使う** | 非公開レイヤーは、しまってあるウインドウがどの操作スペースのものかを知っていますが、公開された仕様ではありません。オフのときAppは画面上のウインドウだけを見ます。 |

Appは15の言語を持ちます — 英語、ロシア語、ドイツ語、フランス語、スペイン語、ポルトガル語
（ブラジル）、イタリア語、オランダ語、ポーランド語、トルコ語、ウクライナ語、日本語、
韓国語、そして中国語の2つの字体 — それ以外では英語で応じます。このガイドの項目名は
日本語で引用しています。

ショートカットには押し続ける修飾キーが必要で、設計上かなえられないものはレコーダーが
断ります。修飾キーのない組み合わせ、すでに **⇧** を含むもの（それは逆方向です）、
**Escape**、`⌘Q`、`⌘W` — そのどれだったかも伝えます。ショートカットは現在の入力ソースの
キーで描かれます。

## 外観

**設定…** の2つめのタブは、プロファイルに保存されるリボンの見た目です。**デフォルト** は
組み込みで編集できません。**複製** すると編集できるコピーができ、**名前** で自分の名前を
付けられます。組み込み以外に持てるのは5つまでで、使用中のものを削除すると **デフォルト**
に戻ります。

| 設定 | 内容 |
|---|---|
| **アイコンの大きさ** | アイコンを描く最大の大きさ。混み合ったリボンでは、画面に収めるためこれより小さくなります。 |
| **アイコンの不透明度** | アイコンをどれだけ濃く描くか。100 % が上限で、それより下げても選択中は目立ちます。プリセットが選択されていないものを薄くするからです。 |
| **リボンの余白** | アイコンとリボンの縁とのあいだの余白。アイコンに対する割合です。 |
| **アイコンの間隔** | アイコン同士のあいだ。同じ割合で指定します。 |
| **角の丸み** | リボンの角の丸さ。 |
| **アイコンの枠**、**枠の余白** | アイコンのまわりに描く輪郭と、そこまでの距離。 |
| **背景** | **ガラス** はシステムの素材です。**暗さ** はそれを暗くし、`0` ではリボンは素のガラスになってデスクトップが透けて見えます。**透明** と **ウインドウの背景色** は素材を持たず、**不透明度** だけで決まります。 |
| **カルーセル** | **選択中の下で列を回す** がオフなら列は動かず、収まるように縮みます。オンなら **枠の数** がいくつのアイコンの中で回すかを決めます（5〜12）。 |
| **選択** | 選択中のアイコンの見分けかた。システムのスイッチャーと同じか、大きくするか、独りだけ際立たせるか、枠で囲むか。 |

どの数値にもスライダと同じ値を示すフィールドがあり、範囲は互いに応じ合います。間隔を
広げれば、そのぶん余白の伸びしろは減ります。**サンプルを表示…** は、選んだ数だけの
ダミーAppでリボンを4秒間描きます。いま使っている操作スペースを乱すことはありません。

## メニューバー

| 項目 | 出る条件 |
|---|---|
| **アクセシビリティを開く…** | 許可がないあいだ — もう一度求めます |
| **入力監視を開く…** | macOS がキー入力を止めているとき（下記参照） |
| **設定…** | 常に |
| **Appとウインドウの一覧をコピー** | 常に — 現在の操作スペースのAppの一覧をクリップボードにコピーします。不具合の報告に添えるのはこれです |
| **Humane Space Tabを終了** | 常に |

## うまくいかないとき

**メニューバーにアイコンがない。** ノッチの左に空きがないメニューバーはアイコンを落とし
ます。macOS は収まらないステータス項目を描かず、Appの側からその場所を確保する手立ては
ありません。空きを作るか、Finder か Spotlight からAppをもう一度開いてください。2回目の
起動は、2つめのコピーではなく設定を開きます。

**macOS がキー入力を止めている、とアイコンが伝える。** **システム設定 → プライバシーと
セキュリティ → 入力監視** に残った古い項目がAppを拒んでいます。その項目を **−** で削除し
——Appに必要なのは許可ではなく、拒否がないことです——Appをクリックし直してください。
再起動なしにタップが作り直されます。

**`⌘Tab` がまだシステムのまま。** 許可がないか、以前のビルドに与えられたものです。
**アクセシビリティを開く…** を使い、一覧にAppの項目がすでにあるなら **−** で削除して、
もう一度許可してください。

**「ログイン時に開く」が保たれない。** macOS が登録を断った場合、その理由がチェック
ボックスの下にシステム自身の言葉で出ます。よくある理由は、システムが見覚えのないビルド
です。ローカルのビルドはそれぞれ独自の ad-hoc 署名を持つため、昨日のコピーが行った登録は
今日のコピーのものではありません。`/Applications` にあるコピーで、いったんオフにしてから
もう一度オンにしてください。

## Appに見えているもの

Appはアクセシビリティという広い権限を持ち、それでできることを意図的にごくわずかに留めて
います。ネットワークのコードはまったくなく、AppleEvents もプラグインもありません。キー
入力はあなたのショートカットと一致するかどうかだけを見ます。ウインドウのタイトルは
ウインドウ切り替えがオンのあいだ、描くためだけに読みます。ポインタはリボン自身のパネルの
上でしか見ません。画面収録は決して求めません。ウインドウのプレビューを出さないのはその
ためです。脅威モデルの全文は [S00](specs/S00-threat-model.md) にあります。
