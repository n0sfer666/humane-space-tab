這個 App 沒有自己的工作視窗：它待在選單列裡，所做的一切都發生在你按住快速鍵的時候。

![切換列](images/ribbon.png)

## 第一次執行

1. 安裝 — `brew install --cask n0sfer666/tap/humane-space-tab`，或從 Releases 打開磁碟
   映像檔，把 **Humane Space Tab.app** 拖到 Applications 的捷徑上 — 然後打開它。
2. 下載來的 App 第一次會被拒絕：打開**系統設定 → 隱私權與安全性**，捲到最下面，按
   **仍要打開**，再打開一次。
3. App 啟動時會要求**輔助使用**。請在**系統設定 → 隱私權與安全性 → 輔助使用**中允許。
   切換器會在幾秒內開始運作，不需要重新打開 App。

選單列圖像是 App 正在執行的唯一憑據：能運作時是 `⇄`，不能運作時是一個警告三角形。macOS
把授權綁在程式碼簽章上，所以每次更新之後都要重新給一次。

## 在 App 之間切換

按住 **⌘** 並輕點 **Tab**。結果取決於你按住多久：

- **快速輕點** —— 短於顯示延遲（預設 120 毫秒）—— 什麼都不顯示，直接切回上一個 App，正如
  手的習慣所預期的那樣。
- **一直按住 ⌘**，切換列就會出現，列出**目前桌面**的 App，最近用過的在前。之後每按一次
  **Tab**，所選項目前進一格。

切換列打開時：

| 按鍵 | 作用 |
|---|---|
| **Tab** | 前進一格 |
| **⇧Tab** | 後退一格 |
| **Escape** | 取消 —— 不切換任何東西 |
| 放開 **⌘** | 切換到所選的 App |

所選的 App 就是畫得更大更實、下方帶名稱的那個圖像；兩側的圖像會變淡。從五個 App 起，切換
列變成輪播：所選項目停在原處，圖像在它下面轉動，因此每走一步在眼裡都是同樣的距離，列表也
沒有盡頭 —— 最後一個 App 之後就是第一個。不到五個時，每個圖像都待在原位，只有所選項目在
移動。切換列到十格就不再變長。

在沒有打開任何東西的桌面上，切換列依然會回應，說明那裡空無一物，而不是把按鍵交還給系統
切換器。

## 在同一個 App 的視窗之間切換

按住 **⌘** 並輕點 **`**（Tab 上方那個鍵）。切換列會列出最前方 App 的視窗 —— 只列目前
桌面上的，按堆疊順序，各帶自己的標題。手勢相同：`⇧` 反向，Escape 取消，放開 **⌘** 把視窗
帶到最前面。

系統快速鍵會把所有桌面的視窗一起算進去，這正是它把你丟到另一個桌面的原因。這個不會：不在
這裡的視窗不會出現在列表裡，所以它從不切換桌面，也不會把收進 Dock 的視窗重新拿出來。

## 滑鼠

切換列打開時，指標在它上面是有效的：

- 在圖像上**移動滑鼠**即可選取它 —— 只是剛好停在切換列彈出位置的指標，在移動之前不會改變
  任何東西；
- **點按**圖像會立刻切換過去，不必等 **⌘** 放開；
- 在切換列上**捲動**可以逐格移動所選項目。

## 設定

從選單列圖像 → **設定…** 打開。

![設定](images/settings.png)

| 設定 | 是什麼 |
|---|---|
| **App** | 打開切換列的快速鍵。按一下輸入欄位並鍵入組合鍵，或用**回復預設值**回到 `⌘Tab`。 |
| **最前方 App 的視窗** | 第二個快速鍵，預設是 `` ⌘` ``。 |
| **在此螢幕顯示切換列** | 具有鍵盤焦點的螢幕，或指標所在的螢幕。 |
| **語言** | 介面語言。**跟隨系統**隨 macOS 而變；App 自帶的語言以各自的名稱列出。選定後視窗立即重繪。 |
| **顯示前的延遲** | 切換列出現之前需要按住快速鍵多久 —— 0 到 500 毫秒。為 `0` 時立即出現。 |
| **登入時打開** | 把 App 註冊為 macOS 的登入項目。 |
| **在視窗之間切換，而不是在 App 之間** | `⌘Tab` 改為列出視窗，和 Windows、Linux 一樣。預設關閉：打開後同一個編輯器的兩份文件就是兩筆項目。 |
| **使用桌面的私有圖層** | 私有圖層知道收進 Dock 的視窗屬於哪個桌面，但它沒有公開文件。關閉時 App 只看螢幕上的視窗。 |

App 自帶十五種語言 —— 英語、俄語、德語、法語、西班牙語、葡萄牙語（巴西）、義大利語、
荷蘭語、波蘭語、土耳其語、烏克蘭語、日語、韓語以及兩種中文字體 —— 其他語言下以英語作答。
本指南中的介面名稱以繁體中文引用。

快速鍵需要一個可以按住的變更鍵，凡是設計上無法兌現的，錄製器都會拒絕 —— 沒有變更鍵的
組合、已經含有 **⇧** 的組合（那是反方向）、**Escape**、`⌘Q` 和 `⌘W` —— 並說明是哪一種。
快速鍵按你目前輸入來源的鍵位繪製。

## 外觀

**設定…** 的第二個標籤頁是切換列的外觀，存放在設定檔裡。**預設**是內建的，不能編輯：
**拷貝**會得到一份可以編輯的副本，**名稱**給它起你自己的名字。內建之外最多五個設定檔；
刪掉正在使用的那個，就回到**預設**。

| 設定 | 是什麼 |
|---|---|
| **圖像大小** | 圖像最大畫到多大 —— 擁擠的切換列為了放進螢幕，仍會把圖像縮到這個值以下。 |
| **圖像不透明度** | 圖像畫得多實。100 % 是上限；低於它時所選項目依然突出，因為預置樣式會讓未選取的部分變淡。 |
| **切換列邊界** | 圖像與切換列邊緣之間的空間，按圖像的比例計。 |
| **圖像之間的間距** | 兩個圖像之間的空間，按同樣的比例計。 |
| **圓角半徑** | 切換列四角有多圓。 |
| **圖像外框**、**外框邊界** | 圍繞圖像畫出的輪廓，以及它與圖像的距離。 |
| **背景** | **玻璃**是系統自身的材質；**暗度**讓它變暗，為 `0` 時切換列就是裸玻璃，桌面透過它清晰可見。**透明**和**視窗背景顏色**不帶材質，只由**不透明度**決定。 |
| **輪播** | 關閉**讓整排在所選項目下方轉動**時，整排不動，會縮小以放得下；開啟時，**格數**決定它在幾個圖像中轉動 —— 5 到 12。 |
| **所選項目** | 所選的圖像靠什麼區分：與系統切換器相同、放大、獨自突顯，或者加上外框。 |

每個數值都有一個滑桿和一個顯示同樣數值的輸入欄位，各自的範圍彼此呼應：把間距調寬，邊界能
長的餘地就變小。**查看範例…**會用你選定數量的佔位 App 畫出切換列，持續四秒，不會打擾你所
在的桌面。

## 選單列

| 項目 | 何時出現 |
|---|---|
| **打開「輔助使用」…** | 權限缺少時 —— 再次要求 |
| **打開「輸入監控」…** | macOS 扣住按鍵時（見下文） |
| **設定…** | 一律 |
| **拷貝 App 與視窗列表** | 一律 —— 把目前桌面的 App 列表拷貝到剪貼板，這正是回報問題時應當附上的內容 |
| **結束 Humane Space Tab** | 一律 |

## 出問題的時候

**選單列裡沒有圖像。** 瀏海左側沒有空位的選單列會把圖像丟掉：macOS 不會繪製放不下的狀態
項目，App 這邊也無法搶佔那個位置。空出一個位置，或從 Finder 或 Spotlight 再次打開 App
—— 第二次啟動打開的是設定，而不是第二份副本。

**圖像說 macOS 扣住了按鍵。** 是**系統設定 → 隱私權與安全性 → 輸入監控**裡 App 的一筆舊
項目在拒絕它。用 **−** 刪掉那筆項目 —— App 需要的不是這項權限，而是沒有拒絕 —— 然後點回
App；事件攔截會重新建立，不必重新啟動。

**`⌘Tab` 仍然是系統的。** 權限缺少，或者屬於上一個版本。用**打開「輔助使用」…**；如果列表
裡已經有 App 的項目，用 **−** 刪掉再重新允許。

**「登入時打開」留不住。** 如果 macOS 拒絕了註冊，它會用自己的話寫在註記框下面。常見原因
是系統不認得的版本：每個本機建置都帶自己的臨時（ad-hoc）簽章，所以昨天那份副本做的註冊不
屬於今天這份。請在 `/Applications` 裡的那份副本上關掉再打開。

## App 能看到什麼

它持有輔助使用這項很寬的權限，卻刻意只用其中極少的一點：完全沒有網路程式碼，沒有
AppleEvents，沒有外掛；按鍵只用來判斷是否與你的快速鍵相符；視窗標題只在按視窗切換開啟時
讀取，而且只為畫出來；指標只在切換列自己的面板上被看到。它從不要求螢幕錄製，這正是它不
顯示視窗預覽的原因。完整的威脅模型見 [S00](specs/S00-threat-model.md)。
