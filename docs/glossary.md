# Glossary

The terms the interface is built on, and how each is said in the fifteen languages S19
carries. It is written before a translation, not after: a word chosen twice is a word the
user meets twice differently.

Two rules decide every entry.

1. **The system's own word wins.** Where macOS already names a thing in a language, we use
   that name. A term we invent is a term the user will not find in System Settings.
2. **Meaning over letters.** Where the English is idiomatic, the translation says what the
   control does in that language's idiom rather than tracking the English word by word.
   *Copy Inventory* copies a diagnostic report of applications and windows; it is translated
   as that, and never as an inventory of goods.

*Space* is the one term where the English name of the feature and the name macOS shows the

word a person will recognise. The app's name keeps *Space*; the sentences do not.

## What is never translated

- **Application names and window titles.** They arrive from macOS and are drawn as they are.
- **The inventory behind Copy Inventory.** It is a bug report; whoever answers the issue
  reads it, and it stays English, `SpaceMembershipLayer.label` included.
- **The app's own name.** *Humane Space Tab* is a name, not a phrase.
- **Key names in a shortcut.** `⌘`, `⌥`, `Tab` and the rest come from the keyboard layout.
