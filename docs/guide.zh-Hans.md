这个 App 没有自己的工作窗口：它待在菜单栏里，所做的一切都发生在你按住快捷键的时候。

![切换条](images/ribbon.png)

## 第一次运行

1. 安装 — `brew install --cask n0sfer/tap/humane-space-tab`，或者从 Releases 打开磁盘
   映像，把 **Humane Space Tab.app** 拖到 Applications 的快捷方式上 — 然后打开它。
2. 下载来的 App 第一次会被拒绝：打开**系统设置 → 隐私与安全性**，滚动到最下面，点按
   **仍要打开**，再打开一次。
3. App 启动时会请求**辅助功能**。在**系统设置 → 隐私与安全性 → 辅助功能**中授予。切换器
   会在几秒内开始工作，不需要重新打开 App。

菜单栏图标是 App 正在运行的唯一凭据：能工作时是 `⇄`，不能工作时是一个警告三角。macOS 把
授权绑定在代码签名上，所以每次更新之后都要重新授予一次。

## 在 App 之间切换

按住 **⌘** 并轻点 **Tab**。结果取决于你按住多久：

- **快速轻点** —— 短于显示延迟（默认 120 毫秒）—— 什么也不显示，直接切回上一个 App，正如
  手上的习惯所预期的那样。
- **一直按住 ⌘**，切换条就会出现，列出**当前桌面**的 App，最近用过的在前。之后每按一次
  **Tab**，选中项前进一格。

切换条打开时：

| 按键 | 作用 |
|---|---|
| **Tab** | 前进一格 |
| **⇧Tab** | 后退一格 |
| **Escape** | 取消 —— 不切换任何东西 |
| 松开 **⌘** | 切换到选中的 App |

选中的 App 就是画得更大更实、下方带名称的那个图标；两侧的图标会变淡。从五个 App 起，切换
条变成轮播：选中项停在原处，图标在它下面转动，因此每走一步在眼里都是同样的距离，列表也
没有尽头 —— 最后一个 App 之后就是第一个。不到五个时，每个图标都待在原位，只有选中项在
移动。切换条到十格就不再变长。

在没有打开任何东西的桌面上，切换条依然会作出回应，说明那里空无一物，而不是把按键交还给
系统切换器。

## 在同一个 App 的窗口之间切换

按住 **⌘** 并轻点 **`**（Tab 上方那个键）。切换条会列出最前面 App 的窗口 —— 只列当前
桌面上的，按堆叠顺序，各带自己的标题。手势相同：`⇧` 反向，Escape 取消，松开 **⌘** 把窗口
调到最前。

系统快捷键会把所有桌面的窗口一起算进来，这正是它把你扔到另一个桌面的原因。这个不会：不在
这里的窗口不会出现在列表里，所以它从不切换桌面，也不会把收进 Dock 的窗口重新拿出来。

## 鼠标

切换条打开时，指针在它上面是有效的：

- 在图标上**移动鼠标**即可选中它 —— 只是恰好停在切换条弹出位置的指针，在移动之前不会改变
  任何东西；
- **点按**图标会立刻切换过去，不必等 **⌘** 松开；
- 在切换条上**滚动**可以逐格移动选中项。

## 设置

从菜单栏图标 → **设置…** 打开。

![设置](images/settings.png)

| 设置 | 是什么 |
|---|---|
| **App** | 打开切换条的快捷键。点按输入框并键入组合键，或用**恢复默认值**回到 `⌘Tab`。 |
| **最前面 App 的窗口** | 第二个快捷键，默认是 `` ⌘` ``。 |
| **在此屏幕显示切换条** | 拥有键盘焦点的屏幕，或指针所在的屏幕。 |
| **语言** | 界面语言。**跟随系统**随 macOS 而变；App 自带的语言以各自的名称列出。选定后窗口立即重绘。 |
| **显示前的延迟** | 切换条出现之前需要按住快捷键多久 —— 0 到 500 毫秒。为 `0` 时立即出现。 |
| **登录时打开** | 把 App 注册为 macOS 的登录项。 |
| **在窗口之间切换，而不是在 App 之间** | `⌘Tab` 改为列出窗口，和 Windows、Linux 一样。默认关闭：打开后同一个编辑器的两个文稿就是两条记录。 |
| **使用桌面的私有图层** | 私有图层知道收进 Dock 的窗口属于哪个桌面，但它没有公开文档。关闭时 App 只看屏幕上的窗口。 |

App 自带十五种语言 —— 英语、俄语、德语、法语、西班牙语、葡萄牙语（巴西）、意大利语、
荷兰语、波兰语、土耳其语、乌克兰语、日语、韩语以及两种中文字体 —— 其他语言下以英语作答。
本指南中的界面名称以简体中文引用。

快捷键需要一个可以按住的修饰键，凡是设计上无法兑现的，录制器都会拒绝 —— 没有修饰键的
组合、已经含有 **⇧** 的组合（那是反方向）、**Escape**、`⌘Q` 和 `⌘W` —— 并说明是哪一种。
快捷键按你当前输入源的键位绘制。

## 外观

**设置…** 的第二个标签页是切换条的外观，保存在配置里。**默认**是内置的，不能编辑：
**复制**会得到一份可以编辑的副本，**名称**给它起你自己的名字。除内置之外最多五个配置；
删掉正在用的那个，就回到**默认**。

| 设置 | 是什么 |
|---|---|
| **图标大小** | 图标最大画到多大 —— 拥挤的切换条为了放进屏幕，仍会把图标缩到这个值以下。 |
| **图标不透明度** | 图标画得多实。100 % 是上限；低于它时选中项依然突出，因为预设会让未选中的部分变淡。 |
| **切换条边距** | 图标与切换条边缘之间的空间，按图标的比例计。 |
| **图标之间的间距** | 两个图标之间的空间，按同样的比例计。 |
| **圆角半径** | 切换条四角有多圆。 |
| **图标外框**、**外框边距** | 围绕图标画出的轮廓，以及它与图标的距离。 |
| **背景** | **玻璃**是系统自身的材质；**暗度**让它变暗，为 `0` 时切换条就是裸玻璃，桌面透过它清晰可见。**透明**和**窗口背景色**不带材质，只由**不透明度**决定。 |
| **轮播** | 关闭**让整排在选中项下方转动**时，整排不动，会缩小以放得下；开启时，**格数**决定它在几个图标中转动 —— 5 到 12。 |
| **选中项** | 选中的图标靠什么区分：与系统切换器相同、放大、独自突出，或者加框。 |

每个数值都有一个滑块和一个显示同样数值的输入框，各自的取值范围彼此呼应：把间距调宽，边距
能长的余地就变小。**查看示例…**会用你选定数量的占位 App 画出切换条，持续四秒，不会打扰你
所在的桌面。

## 菜单栏

| 项目 | 何时出现 |
|---|---|
| **打开“辅助功能”…** | 权限缺失时 —— 再次请求 |
| **打开“输入监控”…** | macOS 扣住按键时（见下文） |
| **设置…** | 始终 |
| **拷贝 App 与窗口列表** | 始终 —— 把当前桌面的 App 列表拷到剪贴板，这正是提交问题时应当附上的内容 |
| **退出 Humane Space Tab** | 始终 |

## 出问题的时候

**菜单栏里没有图标。** 刘海左侧没有空位的菜单栏会把图标丢掉：macOS 不会绘制放不下的状态
项，App 这边也无法抢占那个位置。腾出一个位置，或者从访达或聚焦再次打开 App —— 第二次启动
打开的是设置，而不是第二份副本。

**图标说 macOS 扣住了按键。** 是**系统设置 → 隐私与安全性 → 输入监控**里 App 的一条旧记录
在拒绝它。用 **−** 删掉那条记录 —— App 需要的不是这项权限，而是没有拒绝 —— 然后点回
App；事件捕获会重新建立，不必重启。

**`⌘Tab` 仍然是系统的。** 权限缺失，或者属于上一个版本。用**打开“辅助功能”…**；如果列表里
已经有 App 的记录，用 **−** 删掉再重新授予。

**“登录时打开”留不住。** 如果 macOS 拒绝了注册，它会用自己的话写在复选框下面。常见原因是
系统不认识的版本：每个本地构建都带自己的临时（ad-hoc）签名，所以昨天那份副本做的注册不
属于今天这份。请在 `/Applications` 里的那份副本上关掉再打开。

## App 能看到什么

它持有辅助功能这项很宽的权限，却刻意只用其中极少的一点：完全没有网络代码，没有
AppleEvents，没有插件；按键只用来判断是否与你的快捷键相符；窗口标题只在按窗口切换打开时
读取，而且只为画出来；指针只在切换条自己的面板上被看到。它从不请求屏幕录制，这正是它不显示
窗口预览的原因。完整的威胁模型见 [S00](specs/S00-threat-model.md)。
