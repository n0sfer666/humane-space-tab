# humane-space-tab

Человечный переключатель приложений для macOS.

По `Cmd+Tab` macOS переключается между **всеми** открытыми приложениями, независимо
от того, на каком виртуальном столе (Space) они находятся. `humane-space-tab`
ограничивает переключение приложениями **текущего стола** — и, дальше, распространяет
то же поведение на остальные жесты и функции macOS, связанные с групповым
отображением, сворачиванием и разворачиванием приложений.

> **Статус: пре-релиз.** Переключатель работает. Роадмап ещё меняет заметное
> поведение, поэтому версии остаются ниже `1.0`.

[English version](README.md)

## Цели

- **Нативность** — Swift 6 + AppKit, без кросс-платформенных рантаймов.
- **Малый след** — минимальный размер бандла и потребление памяти.
- **UI/UX** — переключатель должен ощущаться частью системы, а не надстройкой.
- **Автозапуск** — опционально, через штатный системный механизм.
- **Безопасность** — приложению требуется Accessibility; дизайн намеренно сужает
  то, что с этим разрешением можно сделать. См. [Безопасность](#безопасность).

## Безопасность

`humane-space-tab` требует разрешения **Accessibility**: перехватить `Cmd+Tab` и
поднимать окна чужих приложений без него невозможно. Разрешение широкое, поэтому
модель угроз здесь важнее обычного. Обязательства проекта:

- никакого сетевого доступа;
- никаких AppleEvents и скриптового моста в другие приложения;
- никакой плагинной системы и никакого пользовательского кода или скриптов;
- нажатия клавиш анализируются только для сопоставления с настроенным сочетанием,
  не сохраняются, не логируются и никуда не передаются — единственное исключение
  то сочетание, которое вы сами записали как своё;
- заголовки окон читаются только при включённом переключении по окнам и только
  чтобы нарисовать их в ленте: не логируются, не пишутся на диск, никуда не
  передаются;
- курсор виден приложению только над его собственной панелью и только пока лента на
  экране: никакого глобального слежения за мышью, ничего никуда не записывается;
- hardened runtime, никаких entitlements сверх строго необходимых;
- всё проверяемо — исходники открыты полностью, под GPL-3.0.

Приложение запрашивает **Accessibility и ничего больше**. Оно никогда не просит
Screen Recording — а значит, сознательно не показывает превью окон: именно ради
этой функции сопоставимые переключатели держат разрешение, позволяющее читать
содержимое любого окна на экране. Input Monitoring оно тоже не просит: если
устаревшая запись в этом списке заставляет macOS удерживать нажатия клавиш,
меню-бар говорит об этом и открывает панель, где запись можно убрать.

Сборки подписаны **ad-hoc**, Apple Developer ID нет. Два следствия, о которых
стоит знать до установки: macOS попросит заново выдать Accessibility после
каждого обновления, а скачанную сборку придётся один раз разрешить через
System Settings → Privacy & Security.

Полная модель угроз — [S00](docs/specs/S00-threat-model.md).

## Установка

Скачайте последний zip со страницы [Releases](../../releases), распакуйте и перенесите
**Humane Space Tab.app** в `/Applications`.

Первый запуск будет отклонён: macOS помещает в карантин скачанную сборку без Developer
ID. Откройте **System Settings → Privacy & Security**, пролистайте вниз и нажмите
**Open Anyway**, затем запустите приложение снова. Не снимайте атрибут карантина
руками — эта привычка отключает проверку, которая защищает вас от всего остального
скачанного.

Иконка в меню-баре показывает предупреждение, пока не выдан Accessibility. Выберите
**Grant Accessibility…** в её меню — переключатель заработает за пару секунд, без
перезапуска. macOS привязывает это разрешение к подписи кода, поэтому после каждого
обновления его придётся выдать заново.

Если иконка вместо этого сообщает, что macOS удерживает нажатия клавиш, — приложению
отказывает старая запись в **System Settings → Privacy & Security → Input Monitoring**.
Уберите её кнопкой **−** (разрешение приложению не нужно, нужно отсутствие отказа) и
переключитесь обратно в приложение: tap пересоберётся без перезапуска.

### Проверка скачанного

```sh
shasum -a 256 HumaneSpaceTab-<версия>.zip          # сверьте с описанием релиза
gh attestation verify HumaneSpaceTab-<версия>.zip --repo n0sfer/humane-space-tab
```

Аттестация связывает артефакт с запуском workflow и коммитом, который его собрал.

## Требования

- macOS 15 Sequoia или новее
- Apple Silicon или Intel

## Разработка

- **Язык:** Swift 6, AppKit
- **Сборка:** Swift Package Manager для модулей логики, XcodeGen для бандла `.app`
- **Тесты:** Swift Testing, разработка через тесты — тесты идут первыми
- **Ветки:** `main` — защищённая релизная ветка, `dev` — ветка разработки
- **Спеки:** каждая функция проектируется мини-спекой в `docs/specs/` до реализации;
  фундаментальные решения фиксируются как ADR в `docs/adr/`

Нужны Xcode 26 и `brew install xcodegen swiftlint`.

```sh
swift test
swiftlint lint --strict
swift format lint --recursive --strict Sources Tests Package.swift
xcodegen generate
xcodebuild -project HumaneSpaceTab.xcodeproj -scheme HumaneSpaceTab \
  -configuration Release -derivedDataPath .build/xcode build
```

Проект Xcode генерируется из `project.yml` и никогда не коммитится.

Упаковка — один скрипт; release-workflow только вызывает его, поэтому упаковку можно
запустить и сломать на ноутбуке, а не на проде:

```sh
scripts/package.sh 0.1.0        # dist/HumaneSpaceTab-0.1.0.zip и его SHA-256
```

Скрипт отказывается выпускать сборку без одной из архитектур, с entitlements, без
hardened runtime, со сторонней библиотекой или с непроходящей проверкой подписи — и
проверяет каждый срез universal-бинаря отдельно, потому что `codesign` и `otool` по
умолчанию показывают только срез хоста. Тег `v*` запускает тот же скрипт в CI
и публикует пре-релиз; подробности — в [S11](docs/specs/S11-packaging-release.md).

Установка собственной сборки — ещё один скрипт поверх упаковки:

```sh
scripts/install.sh 0.1.0        # упакует, заменит /Applications/Humane Space Tab.app, перезапустит
```

Сначала упаковка, поэтому сборка, не прошедшая проверки, не установится; затем скрипт
завершает работающее приложение, заменяет бандл, сверяет установленную версию и
запускает его. Ожидаемые последние строки — `==> /Applications/Humane Space Tab.app is
0.1.0, running as pid …` и напоминание, что Accessibility нужно выдать заново: у каждой
локальной сборки своя ad-hoc подпись, а macOS привязывает разрешение к подписи.
