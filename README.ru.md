# humane-space-tab

Человечный переключатель приложений для macOS.

По `Cmd+Tab` macOS переключается между **всеми** открытыми приложениями, независимо
от того, на каком виртуальном столе (Space) они находятся. `humane-space-tab`
ограничивает переключение приложениями **текущего стола** — и, дальше, распространяет
то же поведение на остальные жесты и функции macOS, связанные с групповым
отображением, сворачиванием и разворачиванием приложений.

> **Статус: пре-релиз.** Переключатель работает. Роадмап ещё меняет заметное
> поведение, поэтому версии остаются ниже `1.0`.

## Установка

```sh
brew install --cask n0sfer/tap/humane-space-tab
```

Без Homebrew: скачайте `HumaneSpaceTab-<версия>.dmg` со страницы
[Releases](../../releases), откройте и перетащите приложение на ярлык Applications. Рядом
лежит zip с тем же бандлом — для тех, кому так привычнее.

В обоих случаях macOS попросит две вещи, по одному разу:

- **Разрешить первый запуск.** Он будет отклонён, потому что у сборки нет Apple Developer
  ID. Откройте **System Settings → Privacy & Security**, пролистайте вниз, нажмите **Open
  Anyway** и запустите приложение снова. Не снимайте атрибут карантина руками — эта
  привычка отключает проверку, которая защищает вас от всего остального скачанного.
- **Выдать Accessibility.** Приложение просит его при запуске, а его иконка в меню-баре
  показывает предупреждение, пока разрешения нет; **Grant Accessibility…** в её меню
  спрашивает снова. В обоих случаях переключатель заработает за пару секунд, без
  перезапуска. macOS привязывает разрешение к подписи кода, поэтому после каждого
  обновления его придётся выдать заново.

Обновление и удаление — [docs/homebrew.md](docs/homebrew.md). Пропавшая иконка в
меню-баре, удерживаемые системой нажатия, разрешение, выданное прошлой сборке, —
[если что-то не так](docs/guide.ru.md#если-что-то-не-так) в гайде. Что менялось от релиза
к релизу — в [CHANGELOG.md](CHANGELOG.md).

### Проверка скачанного

```sh
shasum -a 256 HumaneSpaceTab-<версия>.dmg          # сверьте с описанием релиза
gh attestation verify HumaneSpaceTab-<версия>.dmg --repo n0sfer/humane-space-tab
```

Аттестация связывает артефакт с запуском workflow и коммитом, который его собрал.
Homebrew сверяет тот же SHA-256 сам.

## Как пользоваться

Держите **⌘** и нажимайте **Tab**. Короткое нажатие переключает на предыдущее приложение,
ничего не показывая; не отпускайте **⌘** — появится лента с приложениями текущего Space:
**Tab** — шаг вперёд, **⇧Tab** — назад, **Escape** отменяет, отпущенный **⌘**
переключает. `` ⌘` `` делает то же самое для окон приложения, которое сейчас впереди. Мышь
тоже работает по ленте: движение выделяет, клик переключает, прокрутка листает.

Оба сочетания, задержка показа, экран, на котором открывается лента, переключение по окнам
и автозапуск — в **Settings…**, в меню иконки в меню-баре.

Полный гайд — каждая настройка, меню-бар и что делать, когда что-то не так — в
[docs/guide.ru.md](docs/guide.ru.md) ([in English](docs/guide.md)).

## Требования

- macOS 15 Sequoia или новее
- Apple Silicon или Intel

## Безопасность

`humane-space-tab` требует разрешения **Accessibility**: перехватить `Cmd+Tab` и
поднимать окна чужих приложений без него невозможно. Разрешение широкое, поэтому
модель угроз здесь важнее обычного. Обязательства проекта:

- никакого сетевого доступа;
- никаких AppleEvents и скриптового моста в другие приложения;
- никакой плагинной системы и никакого пользовательского кода или скриптов;
- нажатия клавиш анализируются только для сопоставления с настроенным сочетанием,
  не сохраняются, не логируются и никуда не передаются — единственное исключение
  то сочетание, которое вы сами записали как своё;
- заголовки окон читаются только при включённом переключении по окнам и только
  чтобы нарисовать их в ленте: не логируются, не пишутся на диск, никуда не
  передаются;
- курсор виден приложению только над его собственной панелью и только пока лента на
  экране: никакого глобального слежения за мышью, ничего никуда не записывается;
- hardened runtime, никаких entitlements сверх строго необходимых;
- всё проверяемо — исходники открыты полностью, под GPL-3.0.

Приложение запрашивает **Accessibility и ничего больше**. Оно никогда не просит
Screen Recording — а значит, сознательно не показывает превью окон: именно ради
этой функции сопоставимые переключатели держат разрешение, позволяющее читать
содержимое любого окна на экране. Input Monitoring оно тоже не просит: если
устаревшая запись в этом списке заставляет macOS удерживать нажатия клавиш,
меню-бар говорит об этом и открывает панель, где запись можно убрать.

Сборки подписаны **ad-hoc**, Apple Developer ID нет. Отсюда оба разовых шага при
установке — и то, что Accessibility приходится выдавать заново после каждого обновления.

Полная модель угроз — [S00](docs/specs/S00-threat-model.md); как сообщить об уязвимости —
[SECURITY.md](SECURITY.md).

## Цели

- **Нативность** — Swift 6 + AppKit, без кросс-платформенных рантаймов.
- **Малый след** — минимальный размер бандла и потребление памяти.
- **UI/UX** — переключатель должен ощущаться частью системы, а не надстройкой.
- **Автозапуск** — опционально, через штатный системный механизм.
- **Безопасность** — приложению требуется Accessibility; дизайн намеренно сужает
  то, что с этим разрешением можно сделать. См. [Безопасность](#безопасность).

## Разработка

Порты и адаптеры, в одну сторону: `SwitcherCore` (чистая логика) → `SystemPorts` →
`SystemAdapters` и `SwitcherUI` → `App`. Swift 6 и AppKit, Swift Package Manager для
модулей и XcodeGen для бандла, Swift Testing везде, `dev` для работы и `main` для
релизов, мини-спека в `docs/specs/` до реализации функции.

```sh
brew install xcodegen swiftlint     # плюс Xcode 26
swift test
scripts/install.sh 0.1.0            # упакует, установит в /Applications, перезапустит
```

Что должно приходить вместе с изменением и остальные команды — в
[CONTRIBUTING.md](CONTRIBUTING.md); упаковка и то, что делает тег `v*`, — в
[S11](docs/specs/S11-packaging-release.md).
